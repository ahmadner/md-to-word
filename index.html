Markdown to Word

Open a Markdown file to preview and edit it, then export it as a Word document, web page, PDF or Markdown. Everything runs in your browser, so your files are never uploaded.

  • Edit with a live preview that matches the Word layout, a formatting toolbar and an outline.
  • A single # Title and a two-column table under it become the cover page; ## Contents becomes a table of contents.
  • mermaid code blocks become diagrams; tables, lists, code and notes are styled.
  • Pick a theme or your own 60-30-10 colors and fonts; they apply to the preview and every export.
  • Your latest changes are kept as a draft in this browser.
Built with docx and Mermaid. Source on GitHub
