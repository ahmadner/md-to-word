Markdown to Word

Turn a Markdown file into a formatted Word document. The conversion runs in your browser, so your file is never uploaded.

  • A single # Title and a two-column table under it become the cover page.
  • A ## Contents section becomes a Word table of contents.
  • mermaid code blocks become diagrams; tables, lists, code and notes are styled.
  • Links to #section anchors become clickable cross-references.
Built with docx and Mermaid. Source on GitHub
